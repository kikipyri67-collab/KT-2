1. Да, alice сможет прочитать notes.txt по полному пути — для этого достаточно бита x на каталоге (он разрешает «проходить сквозь» каталог и обращаться к файлам по имени). Но ls выполнить не сможет — для чтения списка файлов нужен бит r.
2. У копии будет группа alice (её основная группа). setgid не сработает, потому что каталог /home/alice/ не имеет бита setgid — он был только на исходном каталоге, где создавался report.txt.
3. nologin блокирует интерактивный вход (нет оболочки), а одно точечное правило sudo разрешает выполнить только одну конкретную команду. Если бы webapp был в группе sudo, взломщик получил бы полный root-доступ через sudo su. Связка ограничивает ущерб: злоумышленник не может получить shell и может выполнить лишь одну разрешённую операцию.
4. Нет, 777 не даёт webapp никаких дополнительных возможностей по сравнению с 700 — владелец и так имеет rwx. Опасность 777 исключительно в третьей триаде (rwx для others): теперь любой пользователь системы может читать, изменять и выполнять файл, чего не было при 700.
